## 🚀 我学过的 Git 命令

```bash
# 初始化仓库
git init

# 查看状态
git status

# 暂存修改
git add 文件名

# 提交
git commit -m "说明这次改了什么"

# 推送到 GitHub
git push origin main

# 克隆别人的项目
git clone 仓库地址
```
